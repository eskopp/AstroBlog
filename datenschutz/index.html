    Privacy Policy

    Controller

    Erik Skopp (private, non-commercial blog). Further details in the legal notice.

    Overview

    This website is a static site. It sets no cookies, loads no external fonts, scripts or CDNs at runtime and uses no analytics or tracking services. Personal data is essentially only processed in the server log files.

    Hosting and server log files

    The website runs on a server operated by netcup GmbH (location: Nuremberg, Germany). When the pages are accessed, the web server automatically collects data transmitted by your browser and stores it in log files:

    • abbreviated or full IP address
    • date and time of access
    • requested address (URL) and HTTP status code
    • amount of data transferred
    • referrer URL (the previously visited page)
    • browser type and operating system (user agent)

    The legal basis is Art. 6(1)(f) GDPR. The legitimate interest lies in providing the website reliably and securely (including detecting and fending off attack attempts). Log data is deleted after 14 days at the latest, unless it is needed longer to investigate a specific security-relevant incident. Fail2ban is used to ward off automated attacks and temporarily blocks suspicious IP addresses.

    Encryption

    The connection to the website is encrypted with TLS (HTTPS). The certificate is issued by Let’s Encrypt.

    Local storage in your browser (localStorage)

    The website remembers your preference for the light or dark appearance in your browser’s localStorage. This value stays exclusively on your device, is not transmitted to the server and can be deleted by you at any time via your browser settings. It is not a cookie and not tracking.

    Search

    The search runs entirely in your browser. It loads an index file (/search.json) from this server once; the search terms are neither transmitted nor stored.

    RSS feed

    The RSS feed (/rss.xml) is served as a static file from this server. The same information applies as under “server log files”.

    Contact

    This blog does not offer a contact form. If you send me a message by some other means, I process your details solely to handle the enquiry (Art. 6(1)(f) GDPR) and delete them once the enquiry has been dealt with.

    External links

    Posts may contain links to external websites. When you click them you are taken to third-party servers whose data processing is the responsibility of the respective provider. External links open in a new browser tab.

    Your rights

    You have the following rights towards the controller:

    • access to the data stored about you (Art. 15 GDPR)
    • rectification of inaccurate data (Art. 16 GDPR)
    • erasure (Art. 17 GDPR)
    • restriction of processing (Art. 18 GDPR)
    • data portability (Art. 20 GDPR)
    • objection to processing based on Art. 6(1)(f) GDPR (Art. 21 GDPR)

    You also have the right to lodge a complaint with a data protection supervisory authority about the processing of your personal data (Art. 77 GDPR).

    Status

    This privacy policy is dated August 2026.
