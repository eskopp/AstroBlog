    Datenschutzerklärung

    Verantwortlicher

    Erik Skopp (privater, nicht-kommerzieller Blog). Weitere Angaben im Impressum.

    Überblick

    Diese Website ist eine statische Seite. Sie setzt keine Cookies, bindet keine externen Schriftarten, Skripte oder CDNs zur Laufzeit ein und verwendet keine Analyse- oder Tracking-Dienste. Personenbezogene Daten fallen im Wesentlichen nur in den Server-Logdateien an.

    Hosting und Server-Logdateien

    Die Website wird auf einem Server der netcup GmbH (Standort Nürnberg, Deutschland) betrieben. Beim Aufruf der Seiten erhebt der Webserver automatisch Daten, die Ihr Browser übermittelt, und speichert sie in Logdateien:

    • gekürzte bzw. vollständige IP-Adresse
    • Datum und Uhrzeit des Zugriffs
    • angeforderte Adresse (URL) und HTTP-Statuscode
    • übertragene Datenmenge
    • Referrer-URL (die zuvor besuchte Seite)
    • Browsertyp und Betriebssystem (User-Agent)

    Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der technischen Bereitstellung, der Stabilität und der Sicherheit der Website (u. a. Erkennung und Abwehr von Angriffsversuchen). Die Logdaten werden nach spätestens 14 Tagen gelöscht, sofern sie nicht zur Aufklärung eines konkreten sicherheitsrelevanten Vorfalls länger benötigt werden. Zur Abwehr automatisierter Angriffe kommt Fail2ban zum Einsatz, das auffällige IP-Adressen vorübergehend sperrt.

    Verschlüsselung

    Die Verbindung zur Website ist per TLS (HTTPS) verschlüsselt. Das Zertifikat wird von Let’s Encrypt ausgestellt.

    Lokale Speicherung im Browser (localStorage)

    Die Website merkt sich Ihre Einstellung für das helle oder dunkle Erscheinungsbild im localStorage Ihres Browsers. Dieser Wert verbleibt ausschließlich auf Ihrem Gerät, wird nicht an den Server übertragen und kann von Ihnen jederzeit über die Browser-Einstellungen gelöscht werden. Es handelt sich nicht um ein Cookie und nicht um Tracking.

    Suche

    Die Suchfunktion arbeitet vollständig in Ihrem Browser. Sie lädt einmalig eine Index-Datei (/search.json) von diesem Server; die Suchbegriffe werden nicht übertragen und nicht gespeichert.

    RSS-Feed

    Der RSS-Feed (/rss.xml) wird als statische Datei von diesem Server ausgeliefert. Beim Abruf gelten dieselben Angaben wie unter „Server-Logdateien“.

    Kontaktaufnahme

    Dieser Blog bietet kein Kontaktformular an. Wenn Sie mir auf anderem Weg eine Nachricht zukommen lassen, verarbeite ich Ihre Angaben ausschließlich zur Bearbeitung der Anfrage (Art. 6 Abs. 1 lit. f DSGVO) und lösche sie, sobald die Anfrage erledigt ist.

    Externe Links

    Beiträge können Links auf externe Websites enthalten. Beim Anklicken gelangen Sie auf Server Dritter, für deren Datenverarbeitung der jeweilige Anbieter verantwortlich ist. Externe Links öffnen sich in einem neuen Browser-Tab.
